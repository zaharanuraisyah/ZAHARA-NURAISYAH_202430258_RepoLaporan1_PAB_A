# My Little Study Space 🌸

## Deskripsi

My Little Study Space merupakan aplikasi pengelolaan tugas belajar berbasis Flutter yang dikembangkan menggunakan bahasa pemrograman Dart.

Aplikasi ini dirancang untuk membantu pengguna mencatat tugas, mengatur prioritas, memantau tenggat waktu, serta mengelola penyelesaian aktivitas belajar.

## Fitur

* Menambahkan tugas belajar.
* Mengedit dan menghapus tugas.
* Mencari tugas berdasarkan kata kunci.
* Menyaring tugas berdasarkan mata pelajaran.
* Mengatur tanggal dan prioritas tugas.
* Memantau status penyelesaian tugas.
* Menyimpan data secara lokal menggunakan SharedPreferences.

## Teknologi

* Flutter
* Dart
* SharedPreferences

## Cara Menjalankan

1. Pastikan Flutter SDK telah terpasang.
2. Clone repository ini.
3. Buka folder project melalui terminal.
4. Jalankan `flutter pub get`.
5. Jalankan aplikasi menggunakan `flutter run`.
